## Introdução

Este documento é um **folheto do curso** e não um curso completo.
Alguns tópicos requerem a orientação de um professor.

No entanto, os alunos encontrarão aqui uma grande quantidade de informação que, na maioria dos casos, lhes permitirá trabalhar de forma independente.

---

## Leituras recomendadas

Existem alguns livros excelentes sobre Java. Entre eles incluem-se:

1. **Programação em Java**
   Claude Delannoy – Eyrolles

2. **Java Cliente-Servidor**
   Cédric Nicolas, Christophe Avare, Frédéric Najman – Eyrolles

O primeiro livro oferece uma excelente introdução didática à linguagem Java.
Uma vez dominado o seu conteúdo, o segundo livro permite abordar temas mais avançados:

* Java Beans
* JDBC
* CORBA / RMI

Também oferece uma perspetiva industrial sobre Java.

Para explorar Java com maior profundidade em diversos campos, a coleção **«Java Series»** da O’Reilly é uma referência útil.

Para a utilização profissional de Java numa plataforma J2EE:

3. **Programação J2EE**
   Wrox Publishing (distribuído pela Eyrolles)

## Isenção de responsabilidade

Quando este curso foi escrito pela primeira vez (1998), o autor não dominava na perfeição as convenções de codificação do Java.

Naquela altura:

* A linguagem ainda estava nos seus primórdios.
* Não se utilizava qualquer IDE para sinalizar as infrações às convenções de nomenclatura.

Consequentemente:

* Os nomes de classes e interfaces devem começar com maiúscula.
* Esta regra não é seguida de forma coerente no documento.

Além disso, várias das tecnologias apresentadas tornaram-se obsoletas:

* RMI
* CORBA
* Swing
* Applets
* O IDE JBuilder

Em vez de reescrever este documento, em 2015 foi elaborado um novo curso:

👉 **Introdução à linguagem Java e ao ecossistema Spring através de um caso prático (2015)**: 
[https://stahe.github.io/pt-java-spring-dec-2015/](https://stahe.github.io/pt-java-spring-dec-2015/)

Este novo curso baseia-se, em parte, em determinados capítulos deste documento.

Recomenda-se utilizar o curso de 2015 como recurso principal e consultar este documento apenas quando for feita referência ao mesmo.
